# netcut-linux

Monitor bandwidth per-host & kontrol trafik untuk jaringan lokal.

Berbasis reverse engineering terhadap NetCut (arcai.com) untuk Windows,
dijported ke Linux dengan `nftables` + `AF_PACKET` + Scapy.

Sedang dikembangkan. Gunakan `git log` untuk melihat riwayat perubahan.
