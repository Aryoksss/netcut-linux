netcut-linux — cara kerja

Monitor bandwidth per-host & kontrol trafik perangkat di jaringan lokal, dari satu laptop Linux.

Alur paket

  • • Perangkat → router: jalur normal
  • • Setelah ARP spoof: perangkat → laptop
  • • Sniffer hitung byte → nftables → relay
  • • Relay teruskan ke gateway

Mode operasi

  • • capture — monitor + kontrol penuh
  • • fallback-no-root — total per interface
  • • Mode aktif tampil di header dashboard
  • • Scan ulang otomatis saat pindah WiFi

Prasyarat

  • • CAP_NET_RAW — capture paket
  • • CAP_NET_ADMIN — aturan nftables
  • • Alternatif: container docker + --network=host
  • • Dependency: scapy, nftables, hwdata
